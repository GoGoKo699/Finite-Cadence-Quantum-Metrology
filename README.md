# Finite-Cadence Quantum Metrology

**When can quantum error correction retain Heisenberg precision if corrections occur only at a fixed, nonzero time interval?** This project studies the exact noisy evolution between corrections, with a calibrated classical field that physically cancels an adaptive estimate of the signal throughout each interval.

For a finite-dimensional sensor with Hermitian Lindblad noise, let $`\mathcal A=C^*(I,L_1,\ldots,L_m)`$ be the full algebra generated by the noise operators, and let $`G`$ generate the unknown signal. The relevant fixed-cadence criterion uses this entire algebra.

| Setting | Established consequence |
|---|---|
| $`G\notin\mathcal A`$ | A sufficiently small correction interval can be chosen once, independently of the sensing budget $`T`$, to attain global minimax mean-square error $`\Theta(T^{-2})`$. |
| $`G\in\mathcal A`$ | Every fixed positive interval has an $`\Omega(T^{-1})`$ error lower bound, even with adaptive boundary instruments and arbitrary noiseless ancillary memory, for each fixed bounded compensation range. |
| Four-level example $`L=\operatorname{diag}(-3,-1,1,3)`$, $`G=L^3`$ | Arbitrarily fast correction permits global $`\Theta(T^{-2})`$ error, but every positive fixed clock obeys the preceding lower bound. |
| Transverse qubit with known positive noise rate and compensation-grid spacing $`\Delta`$ | In the stated small-band regime, the optimal error is $`\Theta(T^{-2}+\tau\Delta^2/T)`$, uniformly over grid offsets and $`0<\Delta\le\Delta_0\le W`$. |

The lower bound in the second row does not assert that the standard quantum limit is attainable when the parameter is unidentifiable. In the first row the interval is **chosen sufficiently small**, rather than supplied arbitrarily. Every trial, including an unsuccessful localization trial, is charged to a deterministic total sensing-time budget.

## Reproduce the finite checks

From the repository root:

```bash
python3 -m pip install -r verification/requirements.txt
python3 verification/run_all.py
```

The suite checks noncommuting algebra recovery and exact channel derivatives, the transverse-qubit response, grid-estimator margins, physical Choi bounds, and the four-level fast protocol. It writes numerical results under `verification/results/`. Finite matrix computations support their tested cases; the general and asymptotic statements depend on the analytical proofs.

## Scope

The model assumes parameter-independent Hermitian Markovian noise, a known signal generator, ideal instantaneous boundary operations, noiseless ancillas and a calibrated physical compensation field. There is one active sensing system and no access to its environment, no subinterval control and no quantum-coherent control register for the field. The positive theorem tolerates unknown bounded nonnegative rates along known noise directions. The matching grid upper bound assumes the rate is known and positive. Unknown field bias, faulty recovery, noisy ancillas and general non-Hermitian jumps are outside these guarantees.
