# A global estimator with a calibrated field grid

This page proves the upper half of the compensation-resolution law for the transverse-qubit model. The [physical-channel lower bound](grid_lower.md) applies to arbitrary boundary strategies and supplies the matching obstruction. The [general constructive proof](constructive_proof.md) treats continuous compensation and unknown bounded rates; the grid construction here uses a **known rate** in classical data processing.

## 1. Model and result

Only one sensor qubit evolves under

```math
\begin{aligned}
&\dot\rho=-i[(\omega-c)Z/2,\rho]+\gamma(X\rho X-\rho),\\
&\qquad \omega\in[-W,W].
\end{aligned}
\tag{U1}
```

The fixed rate $`\gamma>0`$ and the noise axis are known. One noiseless ancilla qubit and ideal operations at boundaries separated by a fixed $`\tau>0`$ are available. The physical field $`-cZ/2`$ acts throughout a cell. In this construction it is held constant throughout each independently prepared batch.

A calibrated uniform grid of spacing $`\Delta`$ supplies the field values, with arbitrary offset. The allowed grid covers the prior band: each center in $`[-W,W]`$ has an allowed point within $`\Delta/2`$. One may include grid points up to $`\Delta_0/2`$ beyond the endpoints, so $`|c|\le W+\Delta_0/2`$ suffices for every $`0\lt \Delta\le\Delta_0`$. No physical field is switched inside a cell. The number of usable cells is the hard integer budget $`N=\lfloor T/\tau\rfloor`$.

Under the fixed small-band conditions given below, there is a constant $`C`$, independent of $`T`$, $`\Delta`$ and the grid offset, such that

```math
\begin{aligned}
&\sup_{\omega\in[-W,W]}
\mathbb E_\omega(\widehat\omega-\omega)^2
\le C\left(T^{-2}+\frac{\tau\Delta^2}{T}\right).
\end{aligned}
\tag{U2}
```

Every prepared batch, both measurement settings and all failures are charged. Preparation, parity recovery and the two final quantum measurements are fixed. Only the physical grid value and the classical processing of the data depend on the current interval.

For the joint upper/lower theorem impose $`0\lt \Delta\le\Delta_0\le W`$. The condition $`\Delta_0\le W`$ ensures an interior grid gap for the lower bound at every offset. The upper proof itself needs only the stated covering property and the small-band conditions, not that extra gap condition. The result is specific to ideal controls, noiseless memory and exact Markovian dynamics; it does not establish a hardware error threshold.

## 2. Exact corrected cell

Encode logical zero as $`|00\rangle`$ and logical one as $`|11\rangle`$. At each boundary measure $`Z_SZ_A`$ and apply $`X_S`$ on the odd-parity result. The result can then be discarded. With $`V`$ the encoding isometry, this is a fixed decoder followed by re-encoding into the even code space.

The Poisson-jump representation of (U1) has rate $`\gamma`$. A jump path followed by its final parity correction leaves the logical phase generated by

```math
\begin{aligned}
&S=\int_0^\tau(-1)^{N_\gamma(t)}\,dt.
\end{aligned}
\tag{U3}
```

No jump time is observed. This representation is used only to compute the channel. Each corrected cell starts in the even code sector, and independent Markov increments make the cell channels compose.

Introduce dimensionless variables

```math
\begin{aligned}
&x=\tau\omega,\quad u=\tau c,\quad h=\tau\Delta,\\
&\quad \lambda=\gamma\tau,\quad w_0=\tau W,
\quad h_0=\tau\Delta_0.
\end{aligned}
\tag{U4}
```

The corrected channel fixes populations and multiplies the logical $`01`$ coherence by

```math
\begin{aligned}
f(z)&=\mathbb E e^{-izR},\qquad z=x-u,\\
R&=\int_0^1(-1)^{N_\lambda(t)}\,dt\in[-1,1].
\end{aligned}
\tag{U5}
```

For example, its exact closed form is

```math
\begin{aligned}
&f(z)=e^{-\lambda}
\left[\cosh k+(\lambda-iz)\frac{\sinh k}{k}\right],\\
&\qquad k=\sqrt{\lambda^2-z^2},
\end{aligned}
\tag{U6}
```

with $`\sinh k/k=1`$ at $`k=0`$. The expression is independent of the square-root branch. Equivalently,

```math
\begin{aligned}
&f(z)=(1,1)
\exp\!\begin{pmatrix}
-\lambda-iz&\lambda\\
\lambda&-\lambda+iz
\end{pmatrix}
\begin{pmatrix}1\\0\end{pmatrix}.
\end{aligned}
\tag{U7}
```

This follows from the two-state telegraph evolution. No small-$`\tau`$ approximation enters the response used by the estimator.

## 3. Uniform phase and visibility bounds

Let

```math
\begin{aligned}
&a=\mathbb ER=\frac{1-e^{-2\lambda}}{2\lambda}>0,
\qquad v=\mathrm{Var}(R)\le1.
\end{aligned}
\tag{U8}
```

The formulas below have the continuous zero-noise limit $`a=1`$, although the matching grid lower bound requires positive noise. Set $`g(z)=e^{iaz}f(z)`$. Since $`\mathbb E(R-a)=0`$,

```math
\begin{aligned}
&|g(z)-1|\le vz^2/2,
\qquad |g'(z)|\le v|z|.
\end{aligned}
\tag{U9}
```

The first inequality uses $`|e^{-it}-1+it|\le t^2/2`$. For the second, subtract the zero expectation of $`-i(R-a)`$ from the derivative and use $`|e^{-it}-1|\le|t|`$.

Choose

```math
\begin{aligned}
&D=\min\{1/2,a/4\}.
\end{aligned}
\tag{U10}
```

For $`|z|\le D`$, $`|g(z)|\ge1-vz^2/2\ge7/8`$, so $`f`$ has a continuous phase

```math
\begin{aligned}
&f(z)=|f(z)|e^{-i\phi(z)},\qquad \phi(0)=0.
\end{aligned}
\tag{U11}
```

Moreover,

```math
\begin{aligned}
|\phi'(z)-a|
&\le\frac{|g'(z)|}{|g(z)|}
\le\frac{v|z|}{1-vz^2/2}\lt a/2,\\
\frac a2&\le\phi'(z)\le2a,\qquad
|f(z)|\ge e^{-z^2}.
\end{aligned}
\tag{U12}
```

For the phase estimate, the displayed fraction is at most $`(a/4)/(7/8)=2a/7`$. For the visibility estimate, use $`-\log(1-vz^2/2)\le z^2`$ on this range. These are exact finite-cell bounds, uniform on the entire indicated interval.

## 4. Fixed band and grid range

Fix

```math
\begin{aligned}
&\kappa=\tfrac1{16},\qquad r=\tfrac34.
\end{aligned}
\tag{U13}
```

Require the fixed constants $`w_0,h_0`$ to satisfy

```math
\begin{aligned}
&w_0+h_0/2\le D,\qquad
w_0+h_0^2\le\kappa/2,\qquad
w_0\le1/4.
\end{aligned}
\tag{U14}
```

For any fixed finite $`\gamma,W,\Delta_0`$, these hold after choosing $`\tau>0`$ sufficiently small once. Conversely, for a supplied $`\tau`$, they specify a permitted nonshrinking band and maximum mesh. The theorem does not infer global identifiability on an arbitrary larger band at that supplied cadence.

The grid may depend on the target budget through $`0\lt h\le h_0`$, but $`\tau`$, $`W`$, $`\Delta_0`$ and the constants in the proof remain fixed. The continuous-field case is recovered by setting $`h=0`$ and taking the exact interval center as the field value.

## 5. One refinement stage using two fixed measurements

Suppose the current dimensionless interval is $`I=[q-w,q+w]`$, with $`w\le w_0`$. Choose a nearest allowed grid point $`u`$ to its center and set $`d=q-u`$, so $`|d|\le h/2`$. Use

```math
\begin{aligned}
&n=\left\lfloor\frac{\kappa}{w+h^2}\right\rfloor.
\end{aligned}
\tag{U15}
```

Condition (U14) gives

```math
\begin{aligned}
&\frac{\kappa}{2(w+h^2)}\le n\le\frac{\kappa}{w+h^2},
\qquad n\ge1.
\end{aligned}
\tag{U16}
```

For each trial prepare $`|+_L\rangle=(|00\rangle+|11\rangle)/\sqrt2`$ and run $`n`$ corrected cells with the same grid field $`u`$. In one independent set of $`m`$ trials measure the fixed logical $`X`$; in another set of $`m`$ trials measure the fixed logical $`Y`$. Physical realizations are the fixed observables $`X_SX_A`$ and $`Y_SX_A`$ on the final code space.

Writing $`e=x-q`$, their means are

```math
\begin{aligned}
\mathbb EX&=|f(d+e)|^n\cos(n\phi(d+e)),\\
\mathbb EY&=|f(d+e)|^n\sin(n\phi(d+e)).
\end{aligned}
\tag{U17}
```

The known rate and exact response determine the reference phase $`\theta=n\phi(d)`$. Compute it classically and form

```math
\begin{aligned}
&\widehat\mu=\cos\theta\,\overline Y-\sin\theta\,\overline X.
\end{aligned}
\tag{U18}
```

Its expectation is

```math
\begin{aligned}
&\mu(e)=|f(d+e)|^n
\sin\!\left(n[\phi(d+e)-\phi(d)]\right).
\end{aligned}
\tag{U19}
```

The rotated expression is a classical statistic of two fixed quantum measurements. It does not require an adjustable quantum readout phase.

For $`|e|\le w`$, all arguments of $`\phi`$ lie in $`[-D,D]`$. The visibility satisfies

```math
\begin{aligned}
|f(d+e)|^n&\ge e^{-n(d+e)^2}\ge e^{-\kappa},\\
n(d+e)^2
&\le\kappa\frac{(w+h/2)^2}{w+h^2}
\le\kappa(2w+1/2)\le\kappa.
\end{aligned}
\tag{U20}
```

The middle estimate uses $`(w+h/2)^2\le2w^2+h^2/2`$ and $`w\le1/4`$. By (U12), the phase difference in (U19) has the sign of $`e`$ and magnitude at most $`2an|e|\le2\kappa`$. If $`|e|\ge w/2`$, its magnitude is at least $`anw/4`$. Since $`2\kappa\lt \pi/2`$ and $`\sin t\ge2t/\pi`$ for $`0\le t\le\pi/2`$,

```math
\begin{aligned}
&\mathrm{sgn}(e)\,\mu(e)\ge A n w,\\
&\qquad
A=\frac{ae^{-\kappa}}{2\pi}>0,\\
&\qquad w/2\le|e|\le w.
\end{aligned}
\tag{U21}
```

This uniform outer-quarter margin controls a whole interval, rather than only an infinitesimal neighborhood of a selected point.

## 6. Concentration and interval update

The $`2m`$ observations in (U18) are independent. Their weights have a total squared range

```math
\begin{aligned}
&m\left(\frac{2\cos\theta}{m}\right)^2
+m\left(\frac{2\sin\theta}{m}\right)^2
=\frac4m.
\end{aligned}
\tag{U22}
```

Hoeffding's one-sided bound is therefore

```math
\begin{aligned}
&\Pr\{\widehat\mu-\mu\le-t\}\le e^{-mt^2/2},
\end{aligned}
\tag{U23}
```

with the analogous upper-tail inequality. Although its exponent has the same form as a single-quadrature bound, it costs **two** sets of $`m`$ independently prepared batches.

For a nonnegative statistic retain $`[q-w/2,q+w]`$; for a negative one retain $`[q-w,q+w/2]`$. Both candidate intervals contain the central overlap and have half-width $`rw`$. By (U21), excluding a true point in the current interval requires a wrong sign outside that overlap. Thus

```math
\begin{aligned}
&\Pr\{\text{truth excluded at this stage}\mid x\in I\}
\le\exp(-m A^2n^2w^2/2).
\end{aligned}
\tag{U24}
```

All later intervals remain nested, including after a wrong sign. The covering assumption continues to supply a grid point near every possible subsequent center.

## 7. Global risk with all failures included

For $`K`$ stages, let $`w_j=w_0r^j`$, choose $`n_j`$ from (U15) at width $`w_{j-1}`$, and set

```math
\begin{aligned}
C_0&=\frac{6\log(1/r)}{A^2},\\
m_j&=\left\lceil
\frac{C_0(K-j+1)}{n_j^2w_{j-1}^2}
\right\rceil.
\end{aligned}
\tag{U25}
```

The conditional exclusion probability at stage $`j`$ is then at most $`r^{3(K-j+1)}`$. Return the final interval midpoint. On no exclusion its error is at most $`w_K`$; after a first exclusion at stage $`j`$, its distance from the truth remains at most $`2w_{j-1}`$ by nesting. Consequently

```math
\begin{aligned}
\sup_x\mathbb E_x(\widehat x-x)^2
&\le w_K^2+4\sum_{j=1}^K
w_{j-1}^2r^{3(K-j+1)}\\
&\le13w_K^2.
\end{aligned}
\tag{U26}
```

This is the same weighted first-failure argument used in the continuous-field construction. The stage margin here is different: it becomes proportional to $`nw`$ when the grid prevents an exact physical lock.

## 8. Deterministic cell count, including both quadratures

The exact number of consumed cells is

```math
\begin{aligned}
&N_K=2\sum_{j=1}^Km_jn_j.
\end{aligned}
\tag{U27}
```

Let $`k=K-j+1`$ and $`w=w_{j-1}`$. Using (U16) and the ceiling in (U25),

```math
\begin{aligned}
2m_jn_j
&\le2n_j+\frac{2C_0k}{n_jw^2}\\
&\le\frac{2\kappa}{w}
+\frac{4C_0k}{\kappa}
\left(\frac1w+\frac{h^2}{w^2}\right)\\
&\le C_1k\left(\frac1w+\frac{h^2}{w^2}\right),\\
C_1&=2\kappa+4C_0/\kappa.
\end{aligned}
\tag{U28}
```

The geometric sums give

```math
\begin{aligned}
N_K&\le C_2\left(\frac1{w_K}+\frac{h^2}{w_K^2}\right),\\
C_2&=C_1\max\!\left\{\frac r{(1-r)^2},
\frac{r^2}{(1-r^2)^2}\right\}
=C_1\max\{12,144/49\}>1.
\end{aligned}
\tag{U29}
```

There is no omitted logarithmic factor: $`w_{j-1}=w_Kr^{-k}`$ turns the two sums into $`\sum kr^k`$ and $`\sum kr^{2k}`$, respectively.

## 9. A budget rule valid for every integer budget

For $`N\ge1`$, define the positive root

```math
\begin{aligned}
&w_*=
\frac{C_2+\sqrt{C_2^2+4NC_2h^2}}{2N}.
\end{aligned}
\tag{U30}
```

It satisfies $`C_2(1/w_*+h^2/w_*^2)=N`$. If $`w_*>w_0`$, set $`K=0`$ and return the initial midpoint. Otherwise choose

```math
\begin{aligned}
&K=\left\lfloor
\frac{\log(w_0/w_*)}{\log(1/r)}
\right\rfloor.
\end{aligned}
\tag{U31}
```

Then $`w_*\le w_K\lt w_*/r`$, and the monotonicity of the cost bound in (U29) gives $`N_K\le N`$ on every history.

Since

```math
\begin{aligned}
&w_*\le\frac{C_2}{N}+\sqrt{C_2}\frac{h}{\sqrt N},
\end{aligned}
\tag{U32}
```

equation (U26) implies

```math
\begin{aligned}
&\sup_x\mathbb E_x(\widehat x-x)^2
\le C_3\left(N^{-2}+\frac{h^2}{N}\right),\\
&\qquad C_3=\frac{26C_2^2}{r^2}.
\end{aligned}
\tag{U33}
```

If $`w_*>w_0`$, the initial-midpoint risk is at most $`w_0^2\lt w_*^2`$, so the same constant works. If $`N=0`$, use that midpoint without sensing. No asymptotic inversion of an uncharged or random cost is needed.

For $`T\ge\tau`$, $`N=\lfloor T/\tau\rfloor\ge T/(2\tau)`$. Dividing (U33) by $`\tau^2`$ yields

```math
\begin{aligned}
&\sup_\omega\mathbb E_\omega(\widehat\omega-\omega)^2
\le C_3\left(\frac4{T^2}+
\frac{2\tau\Delta^2}{T}\right).
\end{aligned}
\tag{U34}
```

For $`0\lt T\lt \tau`$, the trivial risk $`W^2`$ is bounded by $`W^2\tau^2/T^2`$. Thus (U2) holds for all $`T>0`$, for example with $`C=\max\{4C_3,W^2\tau^2\}`$.

## 10. What precision and resources are used

The number of corrected cells is at most $`N`$; the recovery interval remains exactly $`\tau`$. Each stage uses one selected grid value, so the number of field settings is $`O(\log N)`$. The number of prepared/read batches is the fully charged quantity $`2\sum_jm_j`$. For a fixed nonzero mesh it can grow faster than $`(\log N)^2`$; the continuous-field batch count must not be transferred to this regime.

The rate enters the reference phase $`\phi(d)`$ in classical processing. Knowing only a rate bound is not enough for this construction because the rounded field generally differs from the interval center. The unknown-rate continuous-field theorem therefore does not automatically establish an unknown-rate grid theorem.

Equations (U18)–(U34) describe exact classical coefficients. Finite digital arithmetic can implement the same scaling. If both computed coefficients differ from the exact $`\cos\theta`$ and $`\sin\theta`$ by at most $`Anw/4`$, the statistic changes by at most $`Anw/2`$, since both sample means lie in $`[-1,1]`$. Four times the repetitions in (U25) then restore the same exclusion bound using the halved margin. Replacing $`C_2`$ by $`4C_2`$ in the budget rule preserves its deterministic guarantee. The analytic response can be evaluated to that absolute precision. This increases classical numerical precision, not the number or precision of the quantum readout settings. The model charges sensing time and does not claim constant-cost classical computation.

When $`\Delta=O((\tau T)^{-1/2})`$, the grid term in (U2) is of order $`T^{-2}`$. At fixed $`\tau`$, this is the familiar exponent $`\Delta=O(T^{-1/2})`$. A fixed positive mesh instead gives an $`O(T^{-1})`$ asymptotic upper bound. The [lower proof](grid_lower.md) establishes the matching law for positive noise under the common range $`0\lt \Delta\le\Delta_0\le W`$, even with arbitrary boundary instruments, ancillary memory and boundary-by-boundary choices of grid values.

## 11. Checks, attribution and limits

The [verification directory](../verification/README.md) contains two complementary checks: direct physical density-matrix evolution against the exact corrected-cell response, and a two-state telegraph matrix exponential against the grid phase, visibility and classical-projection identities. Finite numerical cases can detect implementation and sign errors; the uniform statement follows from the inequalities and budget construction above.

The exact transverse response, adaptive inverse-Hamiltonian ideas, quadratic residual loss, noisy global phase-estimation thresholds and weighted nested-interval machinery have relevant predecessors. Their precise contributions are credited in [the related-work comparison](../references/RELATED_WORK.md) and [source list](../references/SOURCES.md). The exponent of the mesh threshold alone is not a new general noisy-phase-estimation result. The operational claim proved here concerns the specified simultaneous physical semigroup, a selectable calibrated grid, fixed quantum measurements, and a complete global risk guarantee under one hard budget.

No jump-time access, within-cell switching, coherent field register, noisy-ancilla tolerance, fixed calibration error or unknown noise direction is included. The theorem does not replace the physical field by a rotation applied only at a cell boundary.
